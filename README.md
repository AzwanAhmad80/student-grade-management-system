## 🌟 Overview

The Student Grade Management System (SGMS) is a modern, user-friendly web application designed to help universities manage student records, track academic performance, and generate insightful analytics. Built specifically for Malaysian universities with support for local naming conventions and IT-focused curricula.

### 🎯 Project Objectives

This system was developed to:
- ✅ Streamline student record management
- ✅ Automate grade tracking and GPA calculation
- ✅ Provide visual analytics for academic performance
- ✅ Enable bulk data import/export capabilities
- ✅ Monitor system performance in real-time
- ✅ Maintain comprehensive activity logs

## 🛠️ Technology Stack

| Component                | Technology | Version  | Purpose                |
|--------------------------|------------|----------|------------------------|
| **Frontend Framework**   | Streamlit  | 1.29.0   | Web UI and interaction |
| **Database**             | SQLite3    | Built-in | Data persistence       |
| **Data Processing**      | Pandas     | 2.1.4    | Data manipulation      |
| **Visualization**        | Plotly     | 5.18.0   | Interactive charts     |
| **System Monitoring**    | psutil     | 5.9.6    | Resource monitoring    |
| **Excel Support**        | openpyxl   | 3.1.2    | Excel file handling    |
| **Programming Language** | Python     | 3.8+     | Core development       |

### Why These Technologies?

- **Streamlit**: Rapid development, interactive UI, Python-native
- **SQLite**: Lightweight, serverless, perfect for single-user applications
- **Pandas**: Powerful data manipulation, CSV handling
- **Plotly**: Beautiful interactive charts, professional visualizations
- **psutil**: Cross-platform system monitoring
- **openpyxl**: Excel file compatibility

## 🚀 How to Run

### Method 1: Command Line (Recommended)

#### Windows
# Navigate to project folder
cd C:\path\to\student-grade-management-system

# Activate virtual environment
venv\Scripts\activate

# Run application
streamlit run app.py

#### macOS / Linux
# Navigate to project folder
cd /path/to/student-grade-management-system

# Activate virtual environment
source venv/bin/activate

# Run application
streamlit run app.py
